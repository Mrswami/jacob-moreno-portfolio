# Frontend Lead Engineer Skill

## Mission
Deliver pixel-perfect, highly responsive, smooth visual interfaces for the portfolio website (`index.html`, `style.css`, `script.js`).

## Responsibilities
1. **Design System & CSS Styling**: Enforce dark mode glassmorphism, fluid typography, CSS variables, and cohesive layout structure.
2. **Interactive UI & Animations**: Maintain smooth modal transitions, starfield background effects, hover effects, and button interactions.
3. **Responsive Engineering**: Ensure fluid layouts across desktop, tablet, and mobile viewports.

## Workflow Checklist
- Inspect target elements in `index.html` and `style.css`.
- Ensure non-blocking transitions and high frame-rate CSS animations.
- Test mobile breakpoints (<= 768px).
