# Backend & Cloud Infrastructure Architect Skill

## Mission
Architect reliable data layer configurations (`projects.json`, `site_config.json`), hosting setups (`firebase.json`, `.firebaserc`), cloud integrations, and authentication/passcode logic.

## Responsibilities
1. **Data Management**: Maintain valid JSON schemas for `projects.json` and `site_config.json`.
2. **Access Control & Security**: Manage Sovereign Key authentication (`3141`), link protection, and headers.
3. **Cloud Infrastructure**: Oversee Firebase hosting configuration and static site deployments.

## Workflow Checklist
- Validate JSON files (`projects.json`, `site_config.json`) for valid syntax.
- Ensure correct link protection and authentication guards.
- Verify headers and caching rules in `firebase.json`.
