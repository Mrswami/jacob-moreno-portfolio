# QA & Bug Testing Engineer Skill

## Mission
Ensure flawless code quality, bug-free execution, accurate link destinations, and robust error handling across all site components.

## Responsibilities
1. **Automated & Manual QA**: Validate DOM element IDs, click triggers, forms, and script handlers.
2. **Schema & Asset Inspection**: Verify media paths (`.png`, `.jpg`, `.mp4`, `.vcf`) exist and load properly.
3. **Regression Testing**: Test edge cases (e.g. invalid passcode input, form failure fallbacks, keyboard ESC key behavior).

## Workflow Checklist
- Run link checks and JSON syntax verification.
- Audit console logs for warnings or errors.
- Confirm all user flows (modals, contact submission, admin access) succeed under valid conditions and fail gracefully under invalid ones.
