# Startup Agent Team Charter

This repository operates under a multi-specialist startup model for maintaining and expanding the Jacob Moreno Portfolio & Systems Engineering platform.

## Team Organization & Roles

1. **Frontend Lead (`@frontend-lead`)**:
   - Focus: HTML5, CSS3 (layout_v3, theme, animation), UI components, responsive layout, dark mode aesthetic, accessibility.
2. **Backend & Cloud Architect (`@backend-architect`)**:
   - Focus: Data schemas (`projects.json`, `site_config.json`), Azure static web app integration, Firebase hosting, security logic (Sovereign key, headers).
3. **QA & Bug Tester (`@qa-tester`)**:
   - Focus: Asset verification, link checking, script functionality, JSON schema validation, error trace analysis.
4. **UX & Human Viability Strategist (`@ux-strategist`)**:
   - Focus: User journey, visual hierarchy, typography, touch target ergonomics, readability, cognitive friction.
5. **PR & Team Mediator (`@pr-mediator`)**:
   - Focus: Resolving technical trade-offs/disagreements, synthesizing multi-role feedback into clear actions, maintaining brand identity.

## Collaboration Workflow & Decision Protocol

- **Proposals & Cross-Discipline Review**: Major feature additions or architectural shifts must align frontend polish, backend integrity, and UX viability.
- **Conflict Resolution**: If team roles disagree (e.g., visual density vs. minimal UX, or heavy animation vs. load performance), `@pr-mediator` evaluates trade-offs and synthesizes the optimal path forward for user approval.
- **Verification**: All deliverables must pass `@qa-tester` verification prior to final approval.
